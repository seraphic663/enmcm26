# 数据与结果

## 输入数据

`data/C题.pdf`给出问题定义和输入、输出要求。`data/附件/`保存配套输入与工作簿模板：

| 材料 | 用途 |
|---|---|
| 附件1 | 典型日电价、负载与光伏曲线 |
| 附件2 | 2025年实际负载与光伏数据 |
| 附件3 | 日内分批发布的光伏预测 |
| 附件4 | 全年动态电价 |
| 附件5 | 五个结果工作簿的格式模板 |

输入以10分钟为时间分辨率。功率、电量、时间标签和正式统计区间的解释见[模型说明](model-scope.md)。

## 论文结果

`result/`保存五份结果工作簿，`table/`保存十九张统计表，`figure/`保存论文六张图。这些文件对应论文的结果展示，并作为重新计算的比对基准。

完整复现从输入附件重新求解模型，保存逐日CSV和逐时段NPZ，再导出工作簿、统计表与图像。校验器将重算结果与固定基准比较，同时根据实际负载、光伏与电价独立核对物理平衡和费用。

数据、论文模板与研究材料的使用条款见[第三方声明](../THIRD_PARTY_NOTICES.md)。
