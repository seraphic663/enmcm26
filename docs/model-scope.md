# 模型与时间口径

## 物理模型

每天144个10分钟区间，功率以1/6小时换算为电量。储能额定容量12000 kWh，SOC范围1200—10800 kWh，初始6000 kWh；充放电效率均为0.9，单区间充放电量不超过5000/6 kWh，禁止同时充放电。

附件中的00:10代表00:00—00:10，0:00+1代表23:50—24:00。P1核对A/B两种端点映射：两者仅改变时间标签，保持144行数值顺序及数学模型一致。P1采用CBC求解、HiGHS独立下界证明及CSV/Excel回读校验，日终SOC回到6000 kWh。

## 全年策略

P2—P4从2025-01-01起回放365天，正式统计2025-02-01至2025-12-31的334天，SOC跨日连续。

- P2完美信息A是全年联合MILP下界对照。Yesterday、Yesterday+70、Dynamic是三个因果策略；Dynamic采用历史候选选择、季节修正、残差修正、状态相关冗余量及包含冗余量的日初MILP。
- P3包括无调整基准和滚动策略。滚动策略在6/12/18点更新光伏预报，保持日初负载预测、冻结储能、禁止少购，仅接受在同一预测下费用更低的调整。
- P4比较Att1/Yest/WD2三种电价预测，以及A、B0、bstar、bfreeze四种调整策略。WD2+bfreeze是主策略，bstar允许储能同步调整；实际电价用于已知前缀修正和事后结算。

P2/P3采用附件1固定电价，P4按附件4实际电价结算。紧急购电价格为当期实际电价的5倍；调整策略按0.5倍当期实际电价计收相对日初计划的绝对偏差费用。

## 导出与校验

工作簿数值按附件自然日顺序填写。P1、P2 A、P3和P4沿用官方模板表头；P2 Dynamic采用自然日表头。部分模板表头偏移不改变数值列的对应顺序。

紧急购电连续区间的显示阈值为P2/P3的1e-6 kWh、P4的1e-7 kWh。物理校验采用1e-5 kWh绝对容差；工作簿、费用及表格比较采用1e-5绝对容差和1e-8相对容差。
